# Paste to HTML Formatter

A simple single-file tool that lets you paste rich text from places like Microsoft Word or web pages and instantly converts it into raw HTML code. 

## How to Use
1. Download the `Paste to HTML.html` file.
2. Open it in any web browser. You do not need a server to run this.
3. Paste your styled text into the editable box.
4. Click the convert button and copy your generated HTML.

## Features
* Completely client-side. No data is sent to any server.
* Preserves underlying formatting like bolding, links, and headers.
* Syntax highlighting included via highlight.js.
